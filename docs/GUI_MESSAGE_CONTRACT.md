# GUI 宿主消息解析

Rondo WebView 的 `postMessage` 发送一个 JSON 字符串，宿主在分派前一次性解析。
本契约只规范界面到宿主的消息读取；既有命令、操作及界面样式保持不变。

- 文档必须是一个平面 JSON 对象，`cmd` 为非空字符串，最多 64 KiB。
- `path`、`mode`、`hex` 为字符串；`pid`、`method` 为有符号 32 位整数字面量；
  `force`、`dark` 为 JSON 布尔值。已提供字段类型不符时拒绝整条消息。
- 缺省值保持原协议：字符串为空，`pid=-1`、`method=0`、`force=false`、`dark=true`。
- 未使用的普通标量字段不影响分派；嵌套对象/数组不属于此协议。
- 支持直接 UTF-8、标准字符串转义、`\uXXXX` 与合法的代理对。拒绝嵌入 NUL、
  不完整代理对、重复键（包括转义后同名）、注释、尾逗号和多文档拼接。
- 错误消息不执行命令，只记录通用提示，不记录消息正文；后续正常消息仍可处理。

使用仓库已固定并校验的 jsoncons 1.10.0，不增加下载依赖。
该版本会丢弃孤立低位代理转义，因此解析前额外验证 Unicode 转义配对；
完整 JSON 语法和 UTF-8 校验仍交由库处理。

回归入口：`ctest --preset msvc-x64-release -R '^gui.messages$' --output-on-failure`。
用例覆盖中文/emoji 路径、字面路径反斜杠、字段名出现在值内、重复字段、类型错误、
整数边界、无效 Unicode/UTF-8、消息大小边界及错误后的恢复。
这些测试只解析数据，不加载 DLL 或执行注入。
